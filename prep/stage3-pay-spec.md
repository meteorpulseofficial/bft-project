Draft written 2026-11-13 **from the PDF only** (Kelvin's build plan, 27 Sep 2026, pp. 1–5, 9–11).

Each rule is a test written as input → expected result. This list is the spec the
crew builds against (HANDOVER section 11.1, step 1). Lines marked **Q-n** depend on an

All times are Kuala Lumpur (UTC+8). All money is in RM and rounded to the sen.

## Open questions for Kelvin (found while writing the tests above)

These are gaps in the plan. Each one changes what a coach gets paid. Settle them before
Stage 3 code, not after.

- **Q-1. Coach rate vs event rate.** The PDF order is coach rate → special event rate →
  default. Read literally, a coach with a personal rate of RM65 working a special event
  that pays RM80 gets RM65. Is that what you want, or should the event rate win?
- **Q-2. Late deduction.** When Owner/GM chooses "deduction", is it a fixed RM amount, a
  %, or typed in each time? Is there a cap?
- **Q-3. Month-end cut-off.** The cut-off date is still open in your checklist. What
  happens to a class that is verified late, or a PT session still pending, after the
  cut-off? Does it move to next month's invoice, or block this one?
- **Q-4. Grace boundary.** Is 10 min 00 s after call time late or on time?
- **Q-5. Leftover sen.** RM2,500 split three ways is RM833.33 each, 1 sen short. Who gets
  it: the first coach, the Lead, or does it stay with the studio?
  *(Since fix #6, 22 Nov: each coach's payout is rounded **down** to the sen and the leftover
  goes to nobody until you answer. Please also confirm rounding down is right — before, it
  rounded to the nearest sen, which could pay out more than the pool.)*
- **Q-6. Cancellation notice.** Your Stage 2 checklist has this open. If the studio
  cancels within X hours, does the coach get any pay?
- **Q-7. Full-timers' extras.** Full-time coaches get no class invoice, but can run PT
  and challenges. Where do their payouts go: an invoice, or payroll?
- **Q-8. Disputes.** A coach can "confirm or dispute" an invoice. Who resolves a dispute,
  and does it block payment of the whole invoice or only the disputed line?
- **Q-9. Coach-specific rates.** Is a personal rate set per position (Lead and Support
  separately) or as one rate for everything?

Not ours to answer: LHDN e-invoicing and PERKESO (Kelvin's accountant), PDPA consent
wording (Kelvin's lawyer). We build what they decide.
